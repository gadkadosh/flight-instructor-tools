# Photo-entry experiment

This experiment will test whether photos of handwritten flight-school sheets can become reviewed teaching records with less effort than the current manual workflow.

The intended workflow is: upload photos, extract a draft, review and correct it beside the originals, and confirm the records for later use in invoicing or logbook exports.

Scaffolding has not started.

The existing [Go CLI](../cli/) provides useful domain examples, but this app can define its own data model and implementation.
